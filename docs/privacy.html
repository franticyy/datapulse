Privacy Policy for DataPulse

Last updated: September 2026

DataPulse is an open-source command-line tool designed for local processing and transfer of genomic sequencing datasets.

Data Access and Storage

DataPulse uses the Google Drive API strictly via the drive.file scope. This means the application only accesses files that are directly created or uploaded by DataPulse itself. The application never accesses, reads, or modifies any other files in your Google Drive.

Personal Information

We do not collect, store, track, or share any personal user information, credentials, or metadata on any external servers. All authentication tokens are stored strictly on your local machine.
